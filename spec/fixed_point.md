# Fixed-point specification (golden model)

Generated by `python scripts/make_fixed_point_spec.py` from `src/features/spec.py`. The golden model (`src/features/golden.py`) follows this table; `scripts/extract_features.py` fails if any feature exceeds its declared width, and `tests/test_features.py` checks it on the fixture.

## 1. Signals and arithmetic

| Signal | Width (signed bits) | Scale | Rounding | Saturation |
|---|---|---|---|---|
| EEG/ECG/EMG input | 16 | 0.25 uV/LSB at 256 Hz | round to nearest (replay software) | clip to int16 |
| Motion input (chest ACC, GYR) | 16 | 2^-12 unit/LSB at 25 Hz | round to nearest (replay software) | clip to int16 |
| Biquad coefficients | <= 18 | 2^-16 | SPT, <= 5 terms | - |
| Biquad accumulator | 40 | 2^-16 x input LSB | floor, 2nd-order error feedback of the 16 discarded bits | - |
| Biquad output (filter state) | 20 | input LSB | - | clip to int20 |
| 1-s block sums of |x| | 29 | input LSB | exact | none needed (256 x 2^20) |
| 2-s window sums | 30 | input LSB | exact (sum of two block registers) | none |
| log2 values | 9 | 2^-3 | leading-one position + 3 truncated mantissa bits; log2(0)=log2(1)=0 | - |
| Counts (zero crossings, extrema, sign agreement, activity) | 11 | count per 2 s window | exact | - |
| Context EMA register | 16 | 2^-6 x feature LSB | floor (arithmetic shift) | - |
| Motion offset EMA register | 24 | 2^-8 x input LSB | floor | - |
| ECG moving integration | 23 | input LSB | exact (32-sample running sum) | - |
| Thermometer inputs | = feature width | feature LSB | comparator `x > threshold` | - |
| LUT-network score | ceil(log2(neurons per class))+1 | popcount difference | exact | - |

Every feature is stored as int16 in `cache/features/int/`.
