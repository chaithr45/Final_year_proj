# ms/: SeizeLUT-MS (mixed-signal co-design study)

Branch `FPGA` only. Planning files at the repository root: `MS_SPEC.md` (goals, specs, decisions, status),
`PREREG.md`, `LOG.md`, `LEARN.md`.

| Path | Content |
|---|---|
| `REPO_MAP.md` | Phase 0 inventory: branches, the frozen detector, where code lives, how to reproduce, brief-vs-repo differences |
| `setup/IIC_OSIC_TOOLS.md` | installing the analog tools (Windows and macOS) |
| `setup/check_tools.sh` | run inside IIC-OSIC-TOOLS: PDK, versions, ngspice smoke test, Magic DRC + netgen LVS |
| `setup/layver_inv/` | known-good inverter from IIC-OSIC-TOOLS test 02 (Apache-2.0, see NOTICE.md) |
| `analog/smoke/` | SKY130 ngspice smoke test (`run_smoke.sh`, netlists, `expected.json` with the cloud reference values) |

Planned (Phase 1+): `py/` (impairment model, sweeps), `fpga/` (impairment emulator RTL and testbenches),
`analog/` (comparator, delta-sigma, front end), `results/` (one folder per phase, every figure regenerated by one script).

Commands:

```bash
# inside IIC-OSIC-TOOLS
bash ms/setup/check_tools.sh
# anywhere with ngspice and a SKY130A PDK
PDK_ROOT=/path/to/pdks bash ms/analog/smoke/run_smoke.sh
```
